QUICK SCAN

This version is styled like the Tight Lines fishing app.

To use the live camera on iPhone, it must be opened from HTTPS.
Deploy this folder to the same hosting method used for Tight Lines, or any static HTTPS host.
Then open the resulting link in Safari and allow Camera access.
Use Share > Add to Home Screen for an app-like icon.

The scanner saves codes locally, ignores duplicates, copies all codes, and exports CSV.
